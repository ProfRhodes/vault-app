# How this vault works

Every note is a plain markdown file. You, Claude and the local mind all read and write the same files, and GitHub keeps them in sync.

## Links

Write `[[note name]]` to link a note. The note you link to shows this one under **Backlinks**, so connections work in both directions.

## Folders

| Folder | Holds |
|---|---|
| notes | Your notes and voice captures |
| memory | What Claude remembers about how you work |
| knowledge | Distilled reference material |

> Raw sources stay on the laptop. Only the distilled markdown lives here.

See [[spreading-activation]] for why links matter so much.
